# Carbon Lens — сценарий показа

Маршрут `/lens`, три роли: владелец проекта, верификатор, инвестор. Показ идёт по ролям: каждая видит
свой экран и свои действия.

**Рамка, которую нужно произнести в начале.** Территории, площади, базовая линия, сцены Sentinel-2,
записи о пожарах, коэффициенты и цены — из официального архива `data/`. Рассчитанные величины приходят
от сервиса; в офлайн-режиме они помечены как условный пример постановки или логический вектор, и эта
пометка видна на экране.

## Запуск

```powershell
cd frontend
npm ci

# офлайн-показ без сервиса
npm run build; npm run preview     # http://127.0.0.1:4173/lens?lens=fixture&demo=1

# показ против живого сервиса
$env:VITE_LENS_API_BASE_URL = 'http://127.0.0.1:8000/api/v2'
npm run build; npm run preview     # http://127.0.0.1:4173/lens?demo=1&auth=demo
```

Учётные записи показа (только в демо-режиме): `owner@demo.local`, `verifier@demo.local`,
`investor@demo.local`, пароль `demo`. В живом режиме роль выбирается той же почтой, а в поле пароля
вводится токен сессии сервиса.

## Ход показа (около 6 минут)

| # | Роль | Действие | Что видно |
|---|---|---|---|
| 1 | Владелец | Выбрать `RU_TVER_01`, период 2019–2024, заявить 3000 единиц, подать заявку | площадь запроса с подписью, откуда она; статус «ждёт верификатора»; кнопки запуска анализа у владельца нет |
| 2 | Верификатор | Открыть заявку из очереди, нажать «Проверить проект» | за 30 секунд: Q, Eproj, R, сценарная стоимость и одна фраза-вывод |
| 3 | Верификатор | Вкладка «Как рассчитано» | шаги от Eproj к Q; каждый раскрывает формулу, подставленные значения и источник параметра |
| 4 | Верификатор | Вкладка «Качество и риски» | четыре покрытия отдельно, сценарный диапазон и чувствительность, предупреждения, три независимые карточки риска |
| 5 | Верификатор | Блок «Заявлено и подтверждено» | заявлено 3000, рассчитано Q, подтверждённая доля, неподтверждённый разрыв и его сценарная стоимость |
| 6 | Верификатор | «Показать ячейки», клик по ячейке на карте | AGB и SD на обе даты, площадь пересечения, источник и оговорка про модельное распределение |
| 7 | Верификатор | Замечание владельцу → «Финализировать паспорт» | паспорт получает статус ФИНАЛИЗИРОВАН и имя верификатора |
| 8 | Инвестор | Открыть паспорт из портфеля | только финализированные паспорта; Q, разрыв, риски, три цены и своя цена |
| 9 | Инвестор | Демонстрационный жизненный цикл | при Q = 0 демо-выпуск недоступен с причиной; подпись «не официальный выпуск и не торговая операция» |
| 10 | Любая роль | Скачать отчёт → проверить загруженный файл | совпадение хеша; изменённая копия обнаруживается |

Полезные ветки показа:

- **Ноль — это результат.** Набор `S1` (контроль по GFC): «Расчёт выполнен, дополнительный эффект не
  подтверждён», причина названа, сценарная стоимость 0 ₽.
- **Недоступно ≠ ноль.** Набор `S7`: «Недостаточно данных для расчёта», сумма не показывается вовсе.
- **Облака ≠ отсутствие биомассы.** Набор `S6`: покрытие CCI 100 %, оптика 18 %, оси разделены.
- **Пожар.** Набор `S2`: зона с признаком горения, официальная запись MODIS с погрешностью даты.
- **Дрейф контракта.** Набор `UNKNOWN_DRIFT`: незнакомые значения становятся нейтральным `UNKNOWN`.
- **Сервис недоступен.** Открыть без сервиса: ошибка названа, офлайн-набор не подставляется сам.

## Чего не говорить

- «Биомасса измерена Sentinel» — Sentinel даёт отражение; биомасса приходит из модельного продукта CCI.
- «Половина леса сгорела» — продукт гарей даёт признак горения с шагом сетки около 463 м.
- «Доказано мошенничество», «greenwashing доказан» — разрыв показывает разницу с расчётом, не умысел.
- «Кредиты», «INVESTABLE», «стоит покупать» — это потенциальные единицы по условиям кейса и сценарная
  стоимость, а не сертифицированные кредиты и не инвестиционный совет.
- «Паспорт защищает от двойной продажи» — хеш выявляет изменение файла, и только это.
