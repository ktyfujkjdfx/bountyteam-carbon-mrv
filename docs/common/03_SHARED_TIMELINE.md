# Общий таймлайн BountyTeam

Все часы — локальное время мероприятия. Кодинг: пятница 19:00 → суббота 23:30.
Официальное расписание и допустимость заготовок тимлид перепроверяет до старта.

| Время | Общий измеримый результат |
|---|---|
| Пт 18:30–19:00 | Ответы кейсодержателя записаны; scope при необходимости обновлён через Decision Log |
| 19:00–19:30 | Гипотеза, реальный кандидат AOI, роли, integration/demo-ноутбуки и contract version зафиксированы |
| 19:30–22:00 | Fixture проходит RS→BE→FE; контракт deploy; issue/balances/buy тестируются |
| 22:00–02:00 | Первый E2E: issue → buy → evidence → freeze → transfer revert; первый скринкаст |
| 02:00–02:15 | Smoke, список блокеров, стабильный tag и handoff |
| 02:15–07:45 | Сон всей команды, включая тимлида |
| 07:45–08:15 | Запуск стабильной сборки и один приоритет на утро |
| 08:15–11:30 | Fixtures заменены реальным bundle; отрицательный/no-data сценарии проверены; stable tag и видео |
| 12:00–14:30 | Экспертная проверка; только правки P0/rubric-gap |
| 14:30–16:30 | P0 и заранее разрешённые P1; учёт обязательного события 15:00–16:30 |
| 16:30–18:00 | Offline/restart/idempotency; feature freeze в 18:00 |
| 18:00–20:00 | Regression, source manifest, финальное видео, release candidate |
| 20:00–22:00 | Запуск вторым участником, репетиция, упаковка |
| 22:00–22:45 | Загрузка решения |
| 22:45–23:30 | Проверка, что платформа открывает точный release; критические исправления упаковки |
| После 23:30 → Вс 10:00 | Слайды/ответы/отдых; сданную функциональность не меняем |

## Проверка на каждом checkpoint

| Время | Вопрос тимлида | Если ответ «нет» |
|---|---|---|
| 22:00 | Каждый потребитель реально принял вход предыдущего модуля? | Чиним границу, прекращаем новые фичи |
| 02:00 | Есть receipt и readback или только UI-toast? | Убираем P1/P2; сохраняем repro |
| 11:30 | Что реально, что synthetic, что cached replay? | Возвращаем честные подписи и P0 |
| 16:30 | Повторный клик/рестарт/нет интернета безопасны? | Feature freeze раньше, исправляем устойчивость |
| 20:00 | Другой человек запускает release по README? | Берём последний работающий tag |
| Перед сдачей | Загруженный файл открыт и совпадает с checksum? | Исправляем сдачу до дедлайна |

## Ритм

- Sync 5–7 минут каждые 2–3 часа: готовый артефакт, следующий срок, блокер,
  помощь/урезание.
- 20 минут без продвижения — эскалация тимлиду с ошибкой и repro.
- После 12:00 новая функция только с решением тимлида.
- После 18:00 субботы только исправления, тесты, видео и упаковка.
