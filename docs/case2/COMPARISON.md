## Что из этого следует

**Участок с изменением — `RU_MORDOVIA_04`.** 1068,7 га нарушений, все тринадцать зон с причиной
`FIRE_SUPPORTED`: внешний продукт гарей MODIS покрывает зону, доля сгоревших пикселей 1,0, даты
03–08.08.2021 с погрешностью 2–10 дней. Потеря пула 72 154 тCO₂-экв. Единиц не будет.

**Контрольный участок — `RU_TVER_01`.** Нарушений в тридцать шесть раз меньше по площади, запас
углерода за период **вырос**: `Eproj = −6 484,7`, то есть пул прибавил. И всё равно `Q = 0`.

**Почему, и это главное.** Базовая линия на том же участке ожидала роста ещё большего:
`Ebase = −11 031,6`. Относительный результат `R = Ebase − Eproj − LK = −4 546,9` — отрицательный.
Лес вырос, но вырос **меньше, чем вырос бы и без проекта**. Дополнительности нет, единиц нет.

Это и есть ответ на greenwashing: существующий и даже прибавляющий лес сам по себе не
превращается в углеродные единицы. Единицы даёт только эффект **сверх** общей базовой линии.

**Зависимость вывода от базовой линии.** На `RU_TVER_01` знак результата определяется не фактом,
а базовой линией: при `Ebase`, меньшем `Eproj` по модулю (то есть при более скромных ожиданиях
роста), `R` стал бы положительным, и участок получил бы ненулевое `Q`. Поэтому базовая линия
зафиксирована в `data/methodology/baseline.csv` и одинакова для всех участков — иначе её можно
было бы подобрать под нужный ответ.

**Неопределённость ограничивает независимо от результата.** Полуширина `H` ведёт себя обратно
площади нарушений: на `RU_TVER_01` `H = 6 689,9` при `|R| = 4 546,9`, то есть `H/R ≥ 1` — даже
положительный `R` такого размера не пережил бы проверку неопределённостью (frozen rule 11).

**Причина изменения устанавливается не всегда, и это записывается честно.** На `RU_VOLOGDA_02`
все 29 нарушенных зон имеют причину `UNKNOWN`: спектральное изменение видно, внешнего
подтверждения нет. Сервис не называет это пожаром и не называет отсутствием изменений.

## Как повторить

```bash
LIVE_REQUIRED=1 python -m backend.tools.live_composition   # или через интерфейс, см. файл по запуску
```

Числа берутся из `units`, `areas`, `coverage`, `zones[]` и `uncertainty` ответа
`GET /api/v2/analyses/{id}`; каждое входит в хеш содержания паспорта.
